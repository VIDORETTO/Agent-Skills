## Filtro Comércio — A REGRA DE OURO (novo v2.0)
Toda notícia/dica/trend, antes de virar post, deve responder: **"Como isso vira peça, serviço ou acessório no balcão AMANHÃ?"**
Se não virar venda, desprioritize. Para isso, use a matriz abaixo — expanda sempre que encontrar novo gatilho:

| Gatilho externo | Dor que cria na moto 100-300cc | O que oferecer no post (estoque/oficina) |
|---|---|---|
| **Frente fria / queda temperatura** | Bateria sofre, óleo engrossa, partida pesada, piloto passa frio | Bateria nova + teste gratuito, óleo correto frio, jaqueta/capa térmica, luva, balaclava |
| **Onda de calor** | Pneu desgasta mais, motor esquenta, óleo afina, resseca borracha | Calibragem/pneu, óleo/fluido, capa banco, protetor solar manopla, revisão arrefecimento |
| **Chuva forte / semana chuvosa** | Visibilidade zero, freio patina, corrente enferruja, capa | Capa chuva, pastilha/lona, pneu sulco, capa moto, lubrificante corrente, viseira anti-embaçante |
| **Seca / poeira** | Filtro ar entope, corrente resseca, carburador sujeira | Filtro ar, limpeza carburador/injeção, lubrificante corrente |
| **Aumento gasolina** | Consumo dispara, vela/filtro velhos gastam mais | Kit revisão economia: vela, filtro ar/combustível, calibragem, relação |
| **Feriado / viagem** | Revisão antes de pegar estrada | Check-up viagem: freio, pneu, óleo, corrente, lâmpada, kit viagem |
| **Volta às aulas** | Pais levam filho garupa, Biz/Pop no dia a dia | Capacete (adulto/infantil), revisão Biz/Pop, baú, capa chuva escolar |
| **IPVA / licenciamento** | Dúvida imposto, documento | Consultoria gratuita + kit documentação + revisão para vistoria |
| **Recall / defeito crônico** | Medo, busca por solução | Diagnóstico gratuito + peça paralela premium corretiva |
| **Lançamento Honda/Yamaha** | Comparação, curiosidade | Comparativo "nova vs sua" + peças compatíveis que já temos |

**Como aplicar:** ao varrer notícias (Tier 2), marque cada candidato com 1 linha "Ângulo comércio:" — ex: "Frente fria prevista 15°C em Araras → Ângulo: jaquetas + baterias com teste na loja". O ranking viral agora usa peso comércio 20%.
